# Learning PHP

This repository is a simple starting point for learning **PHP** from the basics to practical web development.

## What is PHP?

PHP is a server-side scripting language used to build dynamic websites and web applications. It works well with HTML, databases, and form handling.

## Topics to Learn

- PHP syntax and variables
- Data types and operators
- Conditionals and loops
- Functions
- Arrays and strings
- Forms and user input
- Sessions and cookies
- File handling
- Working with databases and MySQL
- Basic security practices

## Getting Started

1. Install PHP on your computer or use a local server stack like XAMPP.
2. Create a file named `index.php`.
3. Add your first PHP code:

```php
<?php
echo "Hello, PHP!";
```

4. Run the file through your local server in a browser.

## Example

```php
<?php
$name = "Developer";
echo "Welcome, $name!";
```

## Best Practices

- Write clean and readable code.
- Use meaningful variable names.
- Validate and sanitize user input.
- Keep learning by building small projects.
